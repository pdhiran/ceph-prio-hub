Root Cause Analysis
RGW returns malformed JSON for deprecated 'get-bucket-notification' S3 API call; not an RGW bug.
ROOT CAUSE: The 'aws s3api get-bucket-notification' command is deprecated in favor of 'get-bucket-notification-configuration'. RGW returns a valid XML response in both cases, but the AWS CLI client expects a different XML schema for the deprecated version and fails to convert it to JSON, producing 'Encountered unrecognized type in JSON encoder'. The issue is in the client-side XML-to-JSON parsing, not in RGW's response. RGW engineer Yuval Lifshitz confirmed via --debug flag that identical correct XML is returned for both API calls.
KEY EVIDENCE
  • Both APIs return same correct XML: <NotificationConfiguration><TopicConfiguration>...</TopicConfiguration></NotificationConfiguration>
  • get-bucket-notification-configuration parses correctly to JSON
  • get-bucket-notification fails JSON conversion due to deprecated client schema expectations
  • Version: ceph 19.2.1-331.el9cp (IBM Ceph 8.0)
  • Confirmed by Yuval Lifshitz: 'this is not an issue with the RGW'
FIX STATUS: Closed as 'not a bug'. The deprecated API produces correct XML; the issue is AWS CLI client-side parsing of the deprecated response format.
Steps to Reproduce
Goal: Demonstrate that get-bucket-notification malformed JSON is a client-side parsing issue.
Environment: IBM Ceph 8.0+ with bucket notifications configured
  • 1. Create SNS topic and configure bucket notification -- intent: set up notification config
  • 2. Run 'aws s3api get-bucket-notification --bucket <bucket> --endpoint-url <rgw>' -- intent: trigger deprecated API path
  • 3. Run same command with --debug flag -- intent: observe raw XML response is valid
  • 4. Run 'aws s3api get-bucket-notification-configuration --bucket <bucket> --endpoint-url <rgw>' -- intent: show correct API works
DIAGNOSTIC COMMANDS
  • aws s3api get-bucket-notification --debug -- shows raw XML response
  • aws s3api get-bucket-notification-configuration -- correct API
  • radosgw-admin topic list -- verify topic configuration
