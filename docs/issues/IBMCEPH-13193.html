Root Cause Analysis
radosgw-admin user info API (/admin/user) missing create_date field that CLI provides.
ROOT CAUSE: The Admin REST API uses a separate dump_user_info() function that was not updated when account-related fields (account_id, path, create_date, tags, group_ids) were added to RGWUserInfo::dump(). The CLI uses the full dump which includes create_date, but the API path omits it. This was fixed upstream in commit 2f7a94c71d32 by Casey Bodley (Jan 2025) which adds the missing encode_json calls for account_id, path, create_date, tags, and group_ids to dump_user_info().
