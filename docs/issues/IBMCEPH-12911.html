Root Cause Analysis
The `ceph tell osd.<id> clear_shards_repaired` command is missing in Squid (IBM Ceph 8.1) but exists in both Reef (lower) and Tentacle (higher) versions.
ROOT CAUSE: The clear_shards_repaired OSD command was not backported to the Squid codebase. The command exists in Reef (18.x) and was added to Tentacle (20.x), but the backport to Squid (19.x) was missed. The upstream fix is at https://github.com/ceph/ceph/pull/60567. This command is needed to clear the OSD_TOO_MANY_REPAIRS health warning after CRC repair operations.
KEY EVIDENCE
  • Command ceph tell osd.0 clear_shards_repaired 0 returns 'no valid command found; Error EINVAL: invalid command'
  • Available in Reef and Tentacle, missing in Squid
  • Upstream PR: https://github.com/ceph/ceph/pull/60567
  • Originally reported via ODF: https://issues.redhat.com/browse/DFBUGS-5290
FIX STATUS: Closed as 'won't do'. The backport to Squid was declined. Users should upgrade to Tentacle (9.x) where the command is available.
