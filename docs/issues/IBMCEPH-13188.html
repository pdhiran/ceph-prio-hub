Root Cause Analysis
'ceph orch ls' misreports OSD service daemon count -- backport of upstream fix to 8.1z6.
ROOT CAUSE: The ceph orchestrator's service listing ('ceph orch ls') incorrectly counts OSD daemons for OSD services. This is a cephadm/orchestrator bookkeeping bug where the running daemon count displayed does not match actual running OSD daemons. The fix was already in the 9.1 branch (MR #1552) and was backported to 8.1z6 (MR #1661). The JIRA description is empty (template only) but the fix is clearly tracked through the merge requests.
