Root Cause Analysis
RGW per-bucket Prometheus metrics missing due to truncated admin socket path and disabled telemetry caches in containerized deployments.
ROOT CAUSE: Two default configuration issues prevent per-bucket RGW metrics from appearing in ceph-exporter: (1) The default admin_socket path is too long in containerized deployments and gets truncated at the Unix socket 108-character limit, preventing ceph-exporter from connecting to RGW's admin socket. (2) RGW telemetry caches (rgw_bucket_counters_cache, rgw_user_counters_cache, rgw_enable_ops_log, rgw_enable_usage_log) are all disabled by default, so even if the socket works, no per-bucket metrics are collected. This is by design but undocumented, confusing customers who expect metrics to work out-of-the-box.
KEY EVIDENCE
  • Workaround confirmed: shortening admin_socket path + enabling telemetry caches resolves the issue
  • Commands: ceph config set global admin_socket '$run_dir/$name.$pid.asok' + enable rgw_bucket_counters_cache/rgw_user_counters_cache
  • Affects RHCS 7 (18.2.1-381.el9cp), reproduced on Squid and Tentacle
  • 100% reproducible on fresh deployments
  • By-design behavior confirmed by Aarti Dhikale per documentation
FIX STATUS: In progress. Configuration issue is by-design, but the admin socket truncation may warrant a default path change. Aarti Dhikale confirmed behavior matches docs. Investigating whether defaults should change.
Steps to Reproduce
Goal: Verify per-bucket RGW metrics are missing by default and appear after configuration changes.
Environment: Any containerized IBM Ceph cluster with RGW.
  • 1. Deploy RGW -- intent: fresh deployment with defaults
ceph orch apply rgw default
  • 2. Create S3 user and generate traffic -- intent: create per-bucket data
radosgw-admin user create --uid=test --display-name=test
s3cmd mb s3://test-bucket && s3cmd put /tmp/testfile s3://test-bucket/
  • 3. Check for per-bucket metrics -- intent: observe they're missing
curl -s http://<rgw-node>:9926/metrics | grep per_bucket
  • 4. Apply workaround configs -- intent: enable metrics
ceph config set global admin_socket '$run_dir/$name.$pid.asok'
ceph config set client.rgw rgw_bucket_counters_cache true
ceph config set client.rgw rgw_user_counters_cache true
ceph orch restart rgw && ceph orch restart ceph-exporter
  • 5. Re-check metrics -- intent: verify they appear
curl -s http://<rgw-node>:9926/metrics | grep per_bucket
