Root Cause Analysis
Parent ticket for mgmt-gateway infinite reconciliation loop. Same root cause and fix as IBMCEPH-17209.
ROOT CAUSE: Same as IBMCEPH-17209 -- dual bug in mgmt-gateway: (1) Missing ssl_trusted_certificate directive causing NGINX OCSP stapling failure, (2) Dependency tracking mismatch in generate_config() causing infinite reconfig loop. Detailed RCA by Aarti Dhikale identified both bugs with proposed fixes. Workaround: set mgmt-gateway to unmanaged.
