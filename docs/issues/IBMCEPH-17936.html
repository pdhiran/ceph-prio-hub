Root Cause Analysis
The `ceph orch osd rebuild` command's `--rebuild-osds-sharing-devices` option is accepted by the CLI parser but never passed to the underlying function, rendering it non-functional.
ROOT CAUSE: Code-level bug in the cephadm orchestrator's CLI handler for orch osd rebuild. The method signature correctly declares the parameter rebuild_osds_sharing_devices: bool = False, but the function body calls self.osd_rebuild(hostname, osd_id) without forwarding the rebuild_osds_sharing_devices argument. The parameter is parsed from the CLI but silently discarded. This means the flag has never worked — any user who relied on --rebuild-osds-sharing-devices to rebuild co-located OSDs on the same device would have gotten single-OSD rebuild behavior instead, potentially leaving shared-device OSDs in an inconsistent state.
KEY EVIDENCE
  • Code snippet from JIRA shows the bug directly:
  def _osd_rebuild(self, hostname: str, osd_id: str, rebuild_osds_sharing_devices: bool = False) -> HandleCommandResult:
      completion = self.osd_rebuild(hostname, osd_id)  # <-- missing rebuild_osds_sharing_devices
  • Reproducible 100%
  • Workaround: ceph orch osd rm --replace --zap (remove and redeploy)

FIX STATUS: Assigned, no fix merged yet. The fix is trivial — pass the parameter through: self.osd_rebuild(hostname, osd_id, rebuild_osds_sharing_devices).
Steps to Reproduce
Goal: Demonstrate that --rebuild-osds-sharing-devices flag is silently ignored.
Environment: Any IBM Ceph version with ceph orch osd rebuild command.
  • 1. Deploy a cluster with OSDs that share devices (e.g., multiple OSDs on same NVMe with WAL/DB partitioning) -- intent: need co-located OSDs to test the flag
  • 2. Identify an OSD sharing a device:
ceph osd metadata <osd-id> | grep -E 'device|bluefs'
-- intent: confirm device sharing
  • 3. Run rebuild WITHOUT the flag:
ceph orch osd rebuild <hostname> <osd-id>
-- intent: establish baseline behavior
  • 4. Run rebuild WITH the flag:
ceph orch osd rebuild <hostname> <osd-id> --rebuild-osds-sharing-devices
-- intent: this should rebuild ALL OSDs on the shared device, but behaves identically to step 3
  • 5. Verify: Only the specified OSD was rebuilt, co-located OSDs were NOT rebuilt
ceph osd metadata <co-located-osd-id>
-- intent: confirm co-located OSDs were not touched
