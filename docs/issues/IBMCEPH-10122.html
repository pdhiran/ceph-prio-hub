Root Cause Analysis
ceph-bluestore-tool help lists `free-fragmentation` as a valid command, but the actual command name is `fragmentation`, causing user confusion.
ROOT CAUSE
The help text in ceph-bluestore-tool's positional options list includes free-fragmentation as a valid command name, but the actual implementation only recognizes fragmentation. The free- prefix was incorrectly added to the help string, likely a copy-paste error from the free-dump and free-score commands listed nearby. Running ceph-bluestore-tool --path <osd-path> --allocator block free-fragmentation returns "unrecognized action" while fragmentation works correctly.
KEY EVIDENCE
  • Help output lists: free-dump, free-score, free-fragmentation but only free-fragmentation is wrong
  • Fix confirmed present in 9.1 downstream (20.1.0 tentacle) but NOT in 8.1
  • Customer (Raimund Sacherer) requests 8.1 backport for MOD customers who won't upgrade to 9.1 soon
  • Related issue: IBMCEPH-15874 (fragmentation_rating label duplication) was split into a separate JIRA
