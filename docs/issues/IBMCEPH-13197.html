Root Cause Analysis
Grafana RGW Sync dashboard shows empty values because the metric name construction regex fails when zone names contain hyphens that get converted to underscores by promethize().
ROOT CAUSE
The ceph-exporter's promethize() function converts hyphens to underscores in metric names. For RGW sync metrics like data-sync-from-<zone>-<counter>, if the zone name contains hyphens (e.g., 'int-abc'), after promethize() the metric becomes ceph_data_sync_from_int_abc_fetch_bytes_sum. The regex that extracts the zone name only captures up to the first underscore, resulting in source_zone="int" with the leftover _abc becoming part of the metric name suffix. Grafana queries ceph_data_sync_from_zone_fetch_bytes_sum but Prometheus has ceph_data_sync_from_zone_abc_fetch_bytes_sum -- mismatch causes empty graphs.
KEY EVIDENCE
  • Anmol Babu analysis: "the fix is to process the zone name before promethize() runs, so the hyphen is preserved"
  • Customer on 7.1z8 still hitting this despite earlier fix for IBMCEPH-861 being present
  • Afreen Misbah: raised PR #70801 "removed regex match completely as its fragile and have both perf group and counter passed instead to construct metric name"
  • Depends on IBMCEPH-14085 for complete resolution
FIX STATUS
  • Status: Post (fix in progress)
  • PR: https://github.com/ceph/ceph/pull/70801 (removes fragile regex, uses perf group+counter directly)
  • Target: z-stream or 9.2
