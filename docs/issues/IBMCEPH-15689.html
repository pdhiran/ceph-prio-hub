Root Cause Analysis
IBM Ceph 9 documentation incorrectly states only RHEL-10 is valid for bootstrap -- RHEL-9 also valid.
ROOT CAUSE: The IBM Storage Ceph 9.9.0 documentation compatibility matrix had a note stating only RHEL-10 was valid for the bootstrap node, which was incorrect. RHEL-9 is also a valid and supported OS for bootstrapping Ceph 9 clusters. This was a documentation oversight introduced during the 9.0 release documentation where a restrictive note was added per engineering request but later confirmed to be too narrow.
