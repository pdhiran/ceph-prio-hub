Root Cause Analysis
RFE to improve 'ceph config log' with ring buffer, log level filtering, and default display-all behavior.
ROOT CAUSE: Feature request. The central config log (1) grows without bound, (2) shows only last 10 entries by default which are dominated by cephadm osd_memory_target autotune adjustments, and (3) should display all entries by default. Requests: (a) mon_central_config_log_entries N ring buffer, (b) mon_central_config_log_level to exclude autotune noise, (c) default to showing all entries.
