Root Cause Analysis
radosgw-admin role list enters infinite loop when role count exceeds ~97, repeating entries endlessly.
ROOT CAUSE: The radosgw-admin role list command has a pagination bug in its OMAP listing logic. When the number of IAM roles exceeds a threshold (observed at 97 roles), the listing marker/cursor logic fails to advance correctly, causing the same set of entries to be returned repeatedly in an infinite loop. The AWS CLI (iam list-roles) uses proper pagination with markers and works correctly with the same data, confirming the bug is in the radosgw-admin CLI pagination implementation, not the underlying role storage.
KEY EVIDENCE
  • Reproducible with 97+ roles on Ceph 19.2.1-331.el9cp (8.1z5)
  • Same role ARN repeated indefinitely: 'arn:aws:iam:::role/anita-test-role-519' appears 10+ times
  • AWS CLI list-roles works correctly with same data
  • Upstream tracker and PR raised by Ashish Singh
  • Reproducer: create 1000 roles using radosgw-admin role create in a loop, then list
FIX STATUS: Upstream PR submitted. Ashish Singh actively working on fix. No downstream target version confirmed yet. Customer awaiting update (Aug 20 follow-up).
