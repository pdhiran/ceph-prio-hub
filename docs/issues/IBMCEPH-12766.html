Root Cause Analysis
OAuth2 integration with Microsoft Entra ID fails due to multiple issues: initial code defect (missing ssl field), then 502 Bad Gateway from routing misconfiguration, and finally 403 Forbidden due to missing Entra ID Premium P1/P2 for role assignment.
ROOT CAUSE
Multiple issues: (1) A downstream merge conflict removed the ssl parameter from Oauth2ProxySpec.__init__(), causing NameError: name 'ssl' is not defined when applying the oauth2-proxy spec. (2) After code fix, the OAuth2 authentication flow completes but returns 502 Bad Gateway due to miscommunication between mgmt-gateway (nginx) and the OAuth2-proxy/Dashboard services. (3) Even when routing works, the Dashboard returns 403 because the Entra ID user has no Ceph Dashboard role assigned -- and assigning custom roles requires Microsoft Entra ID Premium P1/P2.
