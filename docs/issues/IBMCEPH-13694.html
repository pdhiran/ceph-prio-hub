Root Cause Analysis
ceph-volume inventory crashes with RuntimeError when thin-provisioned LVM volumes exist on a node, because it tries to access device nodes that don't exist at the expected /dev/<vgname>/ path.
ROOT CAUSE: The ceph-volume inventory command enumerates all LVM logical volumes including thin pool internal components (_tdata and _tmeta). These internal LVs have symlinks only under /dev/mapper/ (e.g., /dev/mapper/test-thinpool_tdata) but NOT under /dev/<vgname>/ (e.g., /dev/test/thinpool_tdata). The UdevData class in ceph-volume's device.py raises RuntimeError when it cannot find /dev/test/thinpool_tdata. The fix filters out thin pool internal LVs from the inventory enumeration.
KEY EVIDENCE
  • Error: "RuntimeError: /dev/test/thinpool_tdata not found."
  • Stack trace: device.py:322 -> disk.py:1323 raising RuntimeError
  • Reproducer: losetup -f --show /disk.img &amp;&amp; vgcreate test /dev/loop0 &amp;&amp; lvcreate -L 900M -T test/thinpool &amp;&amp; cephadm ceph-volume inventory
  • Confirmed regression: worked in Reef (18.2.1-381) but showed incorrect data; crashes in Squid (19.x)
  • Fix MR: https://gitlab.cee.redhat.com/ceph/ceph/-/merge_requests/1630
FIX STATUS: Fixed in 9.0z2 (verified on 20.1.0-182.el9cp). Also backported to 8.1z6. Blocker severity. Closed as part of 9.0z2 release.
Steps to Reproduce
Goal: Reproduce ceph-volume inventory crash with thin-provisioned LVs
Environment: IBM Ceph 8.1 or 9.0 pre-z2
  • 1. Create a disk image and loop device: dd if=/dev/zero of=/disk.img bs=1M count=1024 &amp;&amp; losetup -f --show /disk.img -- intent: create backing storage
  • 2. Create a volume group: vgcreate test /dev/loop0 -- intent: set up LVM
  • 3. Create a thin pool: lvcreate -L 900M -T test/thinpool -- intent: create thin-provisioned LV that triggers the bug
  • 4. Run ceph-volume inventory: cephadm ceph-volume inventory -- intent: trigger the crash
  • 5. Observe RuntimeError for /dev/test/thinpool_tdata
DIAGNOSTIC COMMANDS
  • ls -la /dev/test/ vs ls -la /dev/mapper/test* -- show path discrepancy
  • lvs -a -- list all LVs including internal ones
  • cephadm ceph-volume inventory 2&gt;&amp;1 -- capture full error
