Root Cause Analysis
Multiple SMB/AD access control issues including incorrect login_control format, SID-to-name resolution failures, and AD groups with spaces not supported.
ROOT CAUSE
This was a tracker bug covering multiple distinct SMB AD integration issues: (1) login_control YAML required domain\\group format with backslash escaping -- customers used incorrect format. (2) SID-to-name resolution intermittently failed in the Security tab. (3) AD groups with spaces (e.g., 'Domain Users') were not supported -- fix PR #66574 available upstream, planned for 9.0z. (4) Setting permissions from MMC not working (requires Windows Explorer). The issues spawned multiple child JIRAs with fixes tracked separately.
