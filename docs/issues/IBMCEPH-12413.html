Root Cause Analysis
S3 object corruption affecting 122,265 objects across 38 buckets -- tail (shadow) RADOS data objects missing, likely due to shared-tail reference issue during bucket operations.
ROOT CAUSE: Object manifests reference tail objects (shadow/multipart parts) that no longer exist in the data pool. For the investigated object, the head object exists but its second shadow chunk is MISSING from default.rgw.buckets.data. The bucket has undergone manual resharding (non-prime shard count=16) and multiple major version upgrades (5.3->7.1->8.1). Suspected root cause is tracker #73348 (shared tail object deletion when using radosgw-admin bucket rm or --bypass-gc with objects that share tail references due to server-side copy). The customer had done version upgrades where server-side copy behavior changed. No definitive RCA provided by engineering due to lack of before-corruption data.
KEY EVIDENCE
  • 122,265 objects affected across 38 buckets
  • Object manifest shows shadow object [MISSING] in rados ls output
  • Bucket check shows index is healthy (sizes match calculated)
  • Objects were believed healthy until Nov 2025
  • Upgrade history: 5.3 (Jul/2025) -> 7.1 (Oct/2025) -> 8.1
  • Related: tracker #73348 and PR #65772 (shared tail deletion on bucket rm)
FIX STATUS: Closed after customer restored from backup. No definitive RCA achieved. Tracker #73348 fix merged upstream.
