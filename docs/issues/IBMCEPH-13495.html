Root Cause Analysis
`ceph orch restart` commands have no effect and `ceph orch ps` shows 'refreshed [X]d ago' for 9+ days, indicating cephadm serve loop is stuck.
ROOT CAUSE: Could not determine root cause due to insufficient log level (INFO only, no DEBUG). The issue is related to the cephadm serve loop's host_needs_daemon_refresh function or, if cephadm agent was enabled, the agent's refresh mechanism. The customer was using cephadm agent which was subsequently disabled due to instability. Running ceph orch ps --refresh manually resolved the issue. Engineering analysis (Timothy Nguyen) identified that the bug likely involves the conditional logic in host_needs_daemon_refresh or agent-mode refresh handling.
