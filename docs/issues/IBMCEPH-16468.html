Root Cause Analysis
Grafana dashboards for RGW and RBD show no data because firewall blocks port 9926 (ceph-exporter) on RGW nodes, preventing Prometheus from scraping metrics.
ROOT CAUSE
The Prometheus targets for ceph-exporter endpoints on the three RGW nodes were in 'down' state with error 'No route to host'. The ceph-exporter service was listening on port 9926, but firewalld was not configured to allow traffic on that port from the Prometheus node. This is a network/firewall configuration issue, not a software bug.
KEY EVIDENCE
  • Aarti Dhikale: "prometheus endpoint target for all of the 3 [RGW node IPs] is in down state because of 'No route to host'"
  • curl: (7) Failed to connect to &lt;IP&gt; port 9926: No route to host
  • Fix: firewall-cmd --add-port=9926/tcp --permanent; firewall-cmd --reload
  • Customer confirmed main dashboards working after fix
  • Version: 18.2.1-381.el9cp (IBM Ceph 7.1)
FIX STATUS
  • Status: Closed (Done)
  • Resolution: Customer added port 9926/tcp to firewall rules on RGW nodes
  • Separate issue opened for Grafana S3 Analytics plugin loading problem
